# Términos de Uso de Murmullo

**Última actualización:** 14 de abril de 2026
**Versión de referencia:** Murmullo v1.9.x

Al descargar, instalar o usar Murmullo aceptas los siguientes términos.
Si no estás de acuerdo, no uses la aplicación.

## 1. Licencia

Murmullo se distribuye bajo la licencia MIT (ver archivo `LICENSE`).
Puedes usar, copiar, modificar y redistribuir el software conforme a
dicha licencia.

## 2. Uso aceptable

Te comprometes a **no**:

- Usar Murmullo para dictar o transcribir contenido que viole leyes
  aplicables (incluyendo difamación, amenazas, material ilegal).
- Intentar eludir los límites del plan gratuito (30 minutos) alterando
  el archivo `usage.json`, clonando instalaciones o técnicas similares.
  Si necesitas más cuota, usa tu propia API key o contrata un plan.
- Redistribuir binarios firmados con el certificado de Murmullo sin
  autorización escrita.
- Usar la aplicación como front-end para servicios de spam, phishing o
  ingeniería social.

## 3. Modelo comercial

- **Plan gratuito:** 30 minutos de audio transcribidos gratuitamente con
  la infraestructura proporcionada por el autor.
- **BYOK (Bring Your Own Key):** Si configuras tus propias API keys de
  OpenAI o Anthropic, no hay límite impuesto por Murmullo; pagas
  directamente a tu proveedor.
- **Planes de pago:** Acceso a infraestructura gestionada sin
  administrar API keys, con cuotas ampliadas. Precios y condiciones
  publicados en el panel de cuenta.

Murmullo se reserva el derecho de modificar precios y cuotas con aviso
previo de 30 días desde el CHANGELOG y correo (si suscrito).
